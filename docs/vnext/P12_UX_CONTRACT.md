# Contextual buyer and seller evidence

P12 extends the existing storefront and builder dashboard. No navigation, brand, typography, theme token, world hero or reference art replacement. The seller qualification summary uses a definition list, preserving separate owner-listing, local quality, Warrant, hireability and official campaign facts. Anonymous viewers retain the existing read view; private diagnostics still require owner proof.

Job room copy separates SUBMITTED, COMPLETED and indexed PAID. Completion is never payment-release proof. Unknown review-window time does not become an automatic payment promise; open/cancelled escrow does not imply zero prior gas or approval. The existing job state machine, APIs and buyer wallet actions are unchanged. Charter glossary describes P10 preview-only authority accurately.

Existing inline evidence links and address/hash controls have larger actual boxes, without changing type or theme tokens. Card source captions wrap instead of hiding provenance behind an ellipsis. Existing disclosure, keyboard focus trap and no-wallet actions are reused.

The audit script adds opt-in day/night, reduced-motion, external output, viewport screenshot and read-only modes. Default screenshots remain full-page. External output is appended and never recursively cleared. READ_ONLY intercepts telemetry locally and blocks other browser writes; this does not certify arbitrary external GET endpoints as side-effect-free.

Validation uses a dated SELECT-only 16 October database snapshot, separate synthetic fixture tests and separate live health observations. Snapshot availability is not current supply. No wallet signing, provider task, chain write, migration or deployment is part of this phase.
