# Offline trial replay v1

P08 uses the explicitly allowed fallback: **comparison UNPROVEN**, no provider winner. This is not a deployed Trials product. No task executor is added.

Existing Ledger manifest SHA-256 canonicalization is reused through a pure `@marque/ledger/trials` subpath. The old benchmark runner, grading, MCS, thresholds, first-party observations and published Ledger are unchanged. Imports do not load the runner, DB or RPC. The new strict JSON context commits task text, exact input text, supplied policy, action chain, pinned block/fork, registration timestamp and explicit equality assertions. These are caller-supplied commitments, not authenticated preregistration or chain evidence. Assertions test exact JSON primitive values through own-property paths, with no coercion or model grading. They do not grade financial wisdom.

`node --import tsx scripts/replay-trial.mts test/fixtures/trial-replay.synthetic.v1.json` reads a regular local UTF-8 JSON file, capped at 2 MiB before parsing. It performs no HTTP, DB, wallet or provider call. Strings, arrays and assertion paths are separately bounded by the versioned schema. Invalid/oversized input exits1 with a redacted error. A successfully inspected report exits0 even when samples fail: exit0 means the replay was inspected, never a fair comparison. All outcomes, output hashes, errors, fork/context mismatches, duplicates and failed assertions remain in the report; raw outputs remain in the input reproduction file. Never upload private tasks or captured outputs without their owner's consent.

The supplied fixture is explicitly SYNTHETIC_FIXTURE, two made-up providers and chain97/block1/fork of repeating1s. It is not a chain observation, an external provider response, elapsed time or cost measurement. One sum is correct and one is wrong. Both cost and elapsed time are null. The report always says UNPROVEN and winner=null, including if every assertion passes. UNVERIFIED_CAPTURE is the only other provenance: it does not authenticate signatures, consent, timing, payment, control or operator independence. No ranking is inferred from output pass counts, latency or fees.

To restore a genuine comparison, establish two independent operators with authenticated consent and safe endpoint operation review; obtain exact same-task quotes, budget and output-rubric acceptance; freeze the same task/input/policy/chain block and preregister the rubric before outputs; capture provider responses and failures with comparable clocks and actual itemized cost. Execute no `message/send`, tools/call, funded notification or payment merely for discovery. New paid actions and chain writes require separate approval. Current historical Plinth/Brain cases are unequal tasks, not a comparison pair.

No HTTP/API/schema/database migration, UI change, new dependency, worker or production deployment. Rollback: revert the new subpath, CLI, fixture and docs; existing rows never change. Private raw candidate descriptors and replay output stay outside Git.
