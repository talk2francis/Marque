# Reporting a security issue

Please report suspected vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/talk2francis/Marque/security/advisories/new). If that form is unavailable, ask for a private contact through the [official Marque Telegram](https://t.me/marque_marketplace). Do not post keys, recovery phrases, exploit instructions or personal information in the public group or an issue.

Include the affected URL or source revision, what you observed, and the smallest safe reproduction. Use testnet and your own test accounts. Do not move anyone else's funds, disrupt agents or access private data to demonstrate an issue. Marque never asks for a private key or recovery phrase.

Reports are reviewed by the maintainer. No response time or bounty is promised. Public security information is available at [security.txt](https://marque.trade/.well-known/security.txt).
